# Movie Info Extractor

A simple Generative AI project that takes a movie description and extracts useful information from it.

## What it does

* Movie title
* Release year
* Genre
* Director
* Cast
* Rating
* Summary

## Technologies

* Python
* Streamlit
* LangChain
* Mistral AI
* Pydantic

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```

Add your Mistral API key in a `.env` file:

```env
MISTRAL_API_KEY=your_api_key_here
```
