# Generative AI Projects

Welcome to my **Generative AI Projects** repository 👋

This repository contains a collection of Generative AI projects that I have developed while learning and exploring **Large Language Models (LLMs), prompt engineering, structured output, LangChain, and AI-powered applications**.

Each project demonstrates the practical implementation of different Generative AI concepts and technologies.

## 📂 Projects

### ✅ Movie Info Extractor

Extract structured movie information from an unstructured movie description using **Mistral AI, LangChain, Pydantic, and Streamlit**.

The application extracts information such as:

* Movie Title
* Release Year
* Genre
* Director
* Cast
* Rating
* Summary

It also demonstrates the use of **PydanticOutputParser** to convert the LLM response into structured data.
